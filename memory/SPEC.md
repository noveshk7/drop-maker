# DROP//MAP MVP Spec

This is the lowercase handoff mirror of `memory/SPEC.md`. DROP//MAP is a local-first esports drop map editor with a seeded Bermuda demo, reusable maps and teams, relative-coordinate drops, tag/logo markers, automatic 1–5 layouts, manual dragging, connector toggles, autosave, and PNG export. No authentication or third-party integrations are used.

Editor changes now use true local project snapshot history: undo/redo covers drops, marker style/size, marker assignment/removal, layer toggles, auto-arrangement, and a whole drag gesture.
